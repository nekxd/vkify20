# VKify20

**VKify20** — тема (themepack) для [OpenVK](https://github.com/openvk/openvk), воссоздающая современный дизайн ВКонтакте (vk.ru 2020→н.в.): белые карточки с мягкими скруглениями, фирменные цвета VK, тёмная тема, официальный набор SVG-иконок VK, обновлённый музыкальный плеер с обложками и многое другое.

![VKify20](res/icons/ovklogowhite.png)

## Возможности

### Внешний вид
- 🎨 **VK-токены**: акцент `#0077FF`, иконки `#71aaeb`, фон `#edeef0`, карточки с радиусом 16px
- 🌓 **Тёмная тема** (в настройках оформления) — настоящие VK-тёмные цвета
- ✅ **Галочка верификации** — официальный VK `verified_20`, голубая `#74acd8`, у самого имени
- 🔴 **Лайк-сердце** — красное `#ff3347`, без текста, счётчик рядом
- 🖼 **Посты** — раздельные карточки, тонкая рамка, компактные и ровные

### Музыка
- 🎵 **Обложки треков** через iTunes Search API (без ключей, кэш 30 дней в localStorage; фолбэк — `song.jpg`)
- ▶️ **Обложка = кнопка воспроизведения**: ховер — затемнение + play, играет — затемнение + пауза
- 🔞 **Explicit-метка** после названия трека
- 📝 Название сверху, исполнитель снизу, длинные строки обрезаются с `…`

### Прочее
- 🎬 **Видео-попап почти на весь экран**, кнопки плеера без заливок
- 💬 Закруглённые баблы в диалогах
- 🔍 VK-стиль поиска: в шапке и на страницах (ui_search)
- 👤 Юзернейм вместо имени в мобильной шапке (шрифт VK Sans — только для юзернеймов)
- ⚙️ Настройки: тёмная тема, граффити VK, **брендинг ВКонтакте** (favicon + лого `vkblack.png`/`vkwhite.png` по темам)

## Установка

1. Скопируйте папку `vk2020/` в `themepacks/` вашего OpenVK.
2. Убедитесь, что `id` в `theme.yml` — `vk2020`.
3. Включите тему в настройках оформления (`/settings?act=interface`) или выставьте её дефолтной:
   ```php
   # Web/Themes/Themepacks.php
   const DEFAULT_THEME_ID = "vk2020";
   ```
4. Сбросьте кэш шаблонов (`tmp/cache/`).

> Для дефолтной темы также нужен фикс `Themepacks.php::offsetExists()` — тема должна отвечать `true` для собственных ресурсов, иначе все `/themepack/...` отдадут 404.

## Структура

```
vk2020/
├── theme.yml            # манифест темы (id, версия, авторы)
├── stylesheet.css       # базовый слой (стили конфликта не создают — см. ниже)
├── tpl/                 # Latte-шаблоны (переопределяют ядро OpenVK)
├── res/
│   ├── css/             # слои: vk2020.css → extras → v3 → v3-pages → v4 → v5 → v5-audio → v6
│   ├── js/              # core (vkify, settings) + ui (обложки, тултипы, музыка)
│   ├── icons/           # спрайты, лого (ovklogoblack/white, vkblack/vkwhite), favicon
│   ├── icons/svg/       # официальные SVG-иконки VK
│   └── vk.ttf           # VK Sans (для юзернеймов)
└── locales-поддержка    # res/php/vkify_i18n.php (ru/en/uk/kk)
```

## Совместимость

- OpenVK (актуальный master)
- PHP 8.2+, MariaDB 10.11 (тестовый стенд)
- Современные браузеры (используются CSS `:has()`, `mask-image`, flex/grid)
